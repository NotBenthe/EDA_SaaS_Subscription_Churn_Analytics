# EDA_SaaS_Subscription_Churn_Analytics
Exploratory Data Analysis (EDA) of the SaaS Subscription &amp; Churn Analytics Dataset. 

The dataset is downloadable [here](https://www.kaggle.com/datasets/rivalytics/saas-subscription-and-churn-analytics-dataset)

" This dataset was generated using ChatGPT and custom Python scripts that simulate real-world SaaS logic with realistic randomness. It includes referential integrity across foreign keys, statistically plausible values (e.g., exponential seat distributions, Poisson usage), and purposeful edge cases like mid-cycle upgrades, missing feedback, and reactivation after churn. All data is fully synthetic — no real users, transactions, or PII — making it safe for educational or public use. "
